# 医疗设备维保授权查询系统

医院按「设备编号 + 服务商名称」查询医疗设备维保授权信息，系统展示维保范围、授权工程师、有效期与服务电话；每次查询均写入审计日志，便于追溯。查不到记录时，页面提供人工核验说明与重新输入入口。

## 功能

- **授权查询**（`/`）：输入设备编号与服务商名称，展示
  - 维保范围
  - 授权工程师（姓名 / 资质证书编号 / 联系电话）
  - 授权有效期（含状态徽标：有效 / 即将到期 / 已过期 / 未生效，到期前 30 天预警）
  - 服务电话（点击可拨号）
- **未命中处理**：提示核对输入，并给出人工核验热线、邮箱、所需材料与处理时限，可一键重新输入
- **查询日志**（`/admin.html`）：记录每次查询的设备编号、服务商名称、是否命中、来源 IP、时间，支持按命中状态筛选
- **容错匹配**：设备编号忽略大小写与空格；服务商名称支持简称模糊匹配

## 快速开始

```bash
npm install
npm start          # http://localhost:3000
```

首次启动自动写入 6 条示例授权数据（`data/authorizations.json`）。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/query` | 查询授权，body：`{"deviceNo":"...","vendorName":"..."}`；每次查询写审计日志 |
| GET | `/api/logs?limit=100&matched=all\|hit\|miss` | 查询日志列表 |
| GET | `/api/health` | 健康检查 |

## 技术说明

- Node.js + Express，JSON 文件持久化（`data/`，原子写入，无需外部数据库）
- 安全：参数化输入校验、每 IP 每分钟 30 次限流、安全响应头、前端 textContent 渲染防 XSS
- 生产部署建议：将 JSON 存储替换为数据库，并为 `/admin.html`、`/api/logs` 增加身份认证
